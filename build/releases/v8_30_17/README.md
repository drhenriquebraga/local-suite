# Local Suite 8.30.17

O instalador abre a seleção de idioma antes de procurar a instalação desta máquina. A busca continua em segundo plano enquanto a janela permanece disponível. A atualização mantém os códigos de LUNG RT 1.1.15 e NEURO RT 1.3.18 e reutiliza os bundles compatíveis da Local Suite 8.30.16.

## Reproduzir o instalador

Use o SETUP público da versão 8.30.16 e o Python 3.12.10 para Windows x64 com zlib 1.3.1. Execute na pasta da receita.

```powershell
python rebuild.py RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.16.zip RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.17.zip
```
