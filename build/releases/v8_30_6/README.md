# Local Suite 8.30.6

Em Configurações, compare os seis esforços de segmentação e acabamento no mesmo corte de SBRT pulmonar. As imagens exibem os contornos relidos do RTSTRUCT de cada esforço. O ULTRA usa o localizador corporal em alta resolução. A demonstração acompanha o pacote e abre sem conexão.

A TC publicada é o caso s0102 de Jakob Wasserthal e colaboradores, do University Hospital Basel. Os cortes foram renderizados com as segmentações produzidas pela Local Suite. [Dataset TotalSegmentator v2.0.1](https://doi.org/10.5281/zenodo.10047292) · [Licença CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## Reproduzir o instalador

O manifesto registra os tamanhos, as somas SHA-256, a versão do Python e a versão da zlib usadas na montagem. Baixe o SETUP anterior e execute o comando abaixo. [SETUP da versão 8.30.5](https://github.com/drhenriquebraga/local-suite/releases/download/v8.30.5/RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.5.zip)

```powershell
python rebuild.py RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.5.zip RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.6.zip
```
