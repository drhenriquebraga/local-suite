# Local Suite 8.28

Rebuild with Python using the [8.27 installer](https://github.com/drhenriquebraga/local-suite/releases/download/v8.27/RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.27.zip) and `python rebuild.py BASELINE.zip OUTPUT.zip`. The manifest verifies every installer file and the finished archive.

For the synthetic checks, extract the rebuilt ZIP into a `setup` folder alongside the `testes` folder. Use the installed Suite Python and run each script in `testes`.
