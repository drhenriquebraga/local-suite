# Local Suite 8.30.10

O RTSTRUCT STUDY volta a preservar a suavização do intestino grosso e do reto. Na junção, o reto Johns Hopkins mantém prioridade nos voxels compartilhados e as lacunas entre os modelos permanecem abertas. A correção também alcança o acabamento da medula, da cauda equina e da descendente anterior quando essa estrutura é selecionada com o plugin de coronárias ativo.

O Neuro RT 1.3.14 apresenta miniaturas ampliáveis das séries carregadas para orientar a escolha das imagens. O Rodar Agora inclui a barra de seleção do esforço de processamento.

## Reproduzir o instalador

Use o SETUP público da versão 8.30.9 e o Python 3.14.6 para Windows x64 com zlib 1.3.1.zlib-ng. Execute na pasta da receita.

```powershell
python rebuild.py RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.9.zip RADIOTERAPIA_AI_LOCAL_SUITE_SETUP_v8.30.10.zip
```
